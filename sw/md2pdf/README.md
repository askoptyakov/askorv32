# md2pdf — документы проекта в PDF

Переводит документы Markdown (`.md`) в PDF формата A4. PDF кладётся рядом с исходным файлом.

```
py sw/md2pdf/md2pdf.py hw/info/performance_roadmap.md hw/info/interrupts.md
```

Ключи:
- `--html` — сохранить рядом и промежуточный `.html`: его удобно открыть в браузере и проверить вёрстку;
- `--browser <путь>` — указать `msedge.exe` или `chrome.exe`, если браузер установлен не в стандартную папку.

## Как работает

1. Markdown переводится в HTML пакетом `markdown` (Python-Markdown): таблицы, блоки кода, якоря разделов.
2. HTML печатается в PDF браузером Microsoft Edge или Google Chrome без окна (`--headless --print-to-pdf`). Оформление задано в скрипте (`CSS`): поля 16 × 14 мм, таблицы и блоки кода не разрываются между страницами, заголовки не остаются внизу страницы.

**Списки.** Документы проекта написаны для GitHub. Python-Markdown строже:
- пункт списка сразу после абзаца он не считает списком;
- вложенным пунктам нужен отступ 4 пробела.

Поэтому перед разбором списки приводятся к его правилам (функция `gfm_lists`). Сами `.md` не меняются.

**Ссылки.** Ссылки на разделы документа (`#якорь`) и на сайты в PDF работают. Ссылки на другие файлы репозитория остаются простым текстом: из PDF они не откроются.

## Что нужно

- Python 3 и пакет `markdown`: `py -m pip install markdown`;
- Microsoft Edge (есть в Windows 10/11) или Google Chrome.
