ПИ-регулятор PIREG
==================

Блок **PIREG** — типовой ПИ-регулятор с одним контуром в фиксированной точке. Его можно использовать двумя способами:

- **через процессор** — программа пишет обратную связь в регистр `FB` и делает шаг командой `CR.STEP`;
- **по прямым связям** с другими блоками в ПЛИС, которые настраивает конфигуратор: обратная связь — среднее за окно блока ADC121, выход — угол блока SIFU, внешние пределы — выходы других регуляторов. Тогда процессор пишет только задание, коэффициенты и пределы.

Из двух таких блоков собирается регулятор выпрямителя «напряжение с ограничением тока» (CV/CC). Как блоки соединены и как работает вся система — в [hw/info/rectifier.md](../../../info/rectifier.md).

Перевода в физические величины в блоке нет. Задание `SP` — в единицах обратной связи: для ADC121 это код АЦП × 16. Выход — в единицах управляемого блока: для SIFU это тики угла. Вольты и амперы в коды пересчитывает программа, когда пишет регистры (`ADC121_MilliToCode16`).

| Файл | Назначение |
|---|---|
| `pireg.sv` | `pireg_top`: регистры по шаблону `periph_regs`, шаг регулятора (4 такта), пределы, антинасыщение |

## Шаг

Шаг выполняется по стробу обратной связи `fb_stb` (при `CR.EN`) или по команде `CR.STEP` (обратная связь берётся из регистра `FB`):

```
e    = SP - FB                              17 бит со знаком
HI   = min(OMAX, lim_i)                     lim_i - при LIM_EN (внешний предел, например выход регулятора тока)
IHI  = min(HI, trk_i)                       trk_i - при TRK_EN (предел интегратора, например выход регулятора напряжения)
INT  = clamp(INT + KI * e, 0, IHI << FRAC)  антинасыщение: интегратор не уходит за предел
OUT  = clamp((KP * e + INT) >> FRAC, 0, HI)
```

- Коэффициенты `KP`, `KI` — 16 бит без знака. Дробных бит `FRAC` — параметр, по умолчанию 12: значение 4096 — это 1,0, наименьший шаг — 1/4096. `KI` задаётся за шаг: при шаге 300 раз в секунду интегральная постоянная — `4096 / (KI · 300)` с.
- Шаг занимает 4 такта: ошибка и пределы → два произведения (2 блока DSP) → интегратор → выход. На 5-м такте выдаётся строб `out_stb` и ставится флаг `SR.RDY`.
- **Пределы.** Выход ограничен диапазоном [0, HI], интегратор — [0, IHI << FRAC]. Поэтому после ограничения выход сразу уходит от предела, как только ошибка меняет знак: «накопленного» сверх предела нет. Флаги: `SR.LIM` — выход на верхнем пределе, `SR.LOW` — на нуле.
- **Вход `run_i`** (при `RUN_EN`): 0 — регулятор остановлен, `INT = 0`, `OUT = 0`, шагов нет. Например, на него подают `SIFU.run`: импульсы сняты — интегратор не копит ошибку, и пуск всегда начинается с нулевого выхода (угол 120°).
- Значения `lim_i` и `trk_i` берутся текущие, то есть выход другого регулятора с его прошлого шага. Два регулятора, связанные друг с другом через `lim` и `trk`, шагают одновременно и видят выходы друг друга с задержкой в один шаг. Комбинационной петли нет.

## Подключение

Блок PIREG — в библиотеке конфигуратора (группа «Своя периферия»): окно адресов по умолчанию `0x1900_0000`, у второго блока — следующее свободное (`0x1A00_0000`). Прерывание — источник PLIC. Выводов у блока нет.

| Параметр | По умолчанию | Смысл | Настройка блока (`.gwsoc`) |
|---|---|---|---|
| `MEMORY_TYPE` | 0 | 1 — данные чтения на следующем такте | — |
| `FRAC` | 12 | дробных бит `KP`, `KI` | «Дробных бит KP, KI» (`frac`, 4…16) |
| `OMAX_INIT` | 0xFFFF | верхний предел выхода после сброса | «Предел выхода после сброса» (`omax`; для угла СИФУ — AMAX, 3333) |
| `LIM_EN`, `TRK_EN`, `RUN_EN` | 0 | входы подключены | ставит конфигуратор по связям `lim`, `trk`, `run` |

| Порт | Смысл | Прямая связь (`links`) |
|---|---|---|
| `fb_i[15:0]`, `fb_stb` | обратная связь и строб нового значения (шаг) | `fb` ← `ADC_V.wmean` (вид `val`) |
| `lim_i[15:0]` | внешний верхний предел выхода и интегратора | `lim` ← `PI_I.out` |
| `trk_i[15:0]` | верхний предел интегратора | `trk` ← `PI_U.out` |
| `run_i` | 1 — работа, 0 — стоп и сброс | `run` ← `SIFU.run` (вид `lvl`) |
| `out_o[15:0]`, `out_stb` | выход и строб нового выхода | выход `out` (вид `val`) → `SIFU.u`, `PI_*.lim/trk` |
| `irq` | `RDY & IE`, через регистр | — |

Не подключённые входы конфигуратор подаёт константами: `fb` — 0 без строба (шаги только командой процессора), `run` — 1.

## Регистры

| Смещение | Имя | Доступ | Биты | Смысл |
|---|---|---|---|---|
| `0x00` | `CR` | чт./зап. | `[0] EN` | шаг по стробу прямой связи `fb_stb` |
| | | | `[1] STEP` | шаг с `FB` (запись 1, сам сбрасывается) |
| | | | `[2] IE` | прерывание по новому выходу (`SR.RDY`) |
| | | | `[3] CLR` | `INT = 0`, `OUT = 0` (запись 1) |
| `0x04` | `SP` | чт./зап. | `[15:0]` | задание, единицы обратной связи |
| `0x08` | `KP` | чт./зап. | `[15:0]` | KP / 2^FRAC |
| `0x0C` | `KI` | чт./зап. | `[15:0]` | KI / 2^FRAC за шаг |
| `0x10` | `OMAX` | чт./зап. | `[15:0]` | верхний предел выхода (нижний — 0) |
| `0x14` | `FB` | чт./зап. | `[15:0]` | обратная связь: пишет процессор; при шаге по прямой связи — значение `fb_i` этого шага |
| `0x18` | `OUT` | чт. | `[15:0]`, `[31:16]` | выход; ошибка `e` последнего шага (16 бит со знаком, с насыщением) |
| `0x1C` | `SR` | чт., зап. 1 | `[0] RDY` | новый выход; сброс записью 1 |
| | | | `[1] LIM`, `[2] LOW` | выход на верхнем пределе / на нуле |
| | | | `[3] RUN` | регулятор работает (`run_i` = 1 или вход не подключён) |
| | | | `[8] BUSY` | идёт шаг |
| `0x20` | `INT` | чт./зап. | `[31:0]` | интегратор со знаком (единицы выхода × 2^FRAC): чтение, предустановка |

## Библиотека на Си (`pireg.h`)

Функции получают указатель на блок (`PI_U`, `PI_I` — имена из конфигуратора).

| Функция | Действие |
|---|---|
| `PIREG_Init(pi, kp, ki, omax)` | стоп, `INT = 0`, `OUT = 0`, коэффициенты, предел выхода |
| `PIREG_GAIN(PI_U, 0.05)` | коэффициент-константа в единицах блока (k × 2^FRAC) |
| `PIREG_SetPoint`, `PIREG_SetGains`, `PIREG_SetMax` | задание, коэффициенты, предел |
| `PIREG_Enable`, `PIREG_Disable` | шаги по прямой связи вкл./выкл. |
| `PIREG_Step(pi, fb)` | шаг от процессора: возвращает новый выход |
| `PIREG_GetOut`, `PIREG_GetError`, `PIREG_GetFb` | выход, ошибка и обратная связь последнего шага |
| `PIREG_AtLimit`, `PIREG_Running`, `PIREG_Ready`, `PIREG_ClearReady` | состояние, флаг RDY |
| `PIREG_Clear`, `PIREG_IT_Enable` | сброс интегратора и выхода; прерывание (источник `PLIC_SRC_<ИМЯ>`) |

```c
#include "pireg.h"

PIREG_Init(PI_U, PIREG_GAIN(PI_U, 0.02), PIREG_GAIN(PI_U, 0.0125), SIFU_GetAlphaMaxExt());
PIREG_SetPoint(PI_U, ADC121_MilliToCode16(ADC121_CAL(ADC_V), 50000));   //50 В
PIREG_Enable(PI_U);                     //Шаги - по средним ADC_V (связь fb <- ADC_V.wmean)
SIFU_ExtEnable();                       //Угол = AMAX - выход PI_U (связь SIFU.u <- PI_U.out)
```

## Тест (`tb_pireg.sv`)

Четыре экземпляра на одной шине, выбор — биты адреса `[25:24]`:
- `dut` — без внешних входов: значения после сброса; П-часть (`KP` = 1 и 1,5); И-часть (`KI` = 0,5: 50, 100, 150, `INT` = 150 · 4096); предел `OMAX` с флагом `LIM` и уход от предела без «накопленного»; нуль с флагом `LOW` и интегратором не ниже 0; предустановка `INT` и `CLR`; шаг по прямой связи (без `EN` его нет, с `EN` — один строб `out_stb`, `FB = fb_i`); прерывание `IE`;
- `dl` — `LIM_EN`, `TRK_EN`, `RUN_EN`: `lim_i` ограничивает выход и интегратор, `trk_i` — только интегратор, `run_i` = 0 — выход 0, интегратор 0, шагов нет;
- `pu` и `pc` — **замкнутый контур CV/CC**. `pu` — регулятор напряжения с пределом `lim` = выход `pc`, `pc` — регулятор тока с пределом интегратора `trk` = выход `pu`. Модель выпрямителя: U = 4 · u, I = U · 1000 / R, каждый «сектор» оба регулятора получают U и I стробом. Проверки:
  - лёгкая нагрузка — напряжение стабилизировано (2000 ± 10), ток ниже предела, `pu` не на пределе;
  - тяжёлая — ток ограничен (1500 ± 10), напряжение снизилось, `pu` на пределе от `pc`;
  - нагрузку сняли — снова напряжение, перерегулирование не больше 10 %;
  - резкий наброс — ток выше 1800 не дольше 3 секторов, затем 1500.

Всего 53 проверки.
