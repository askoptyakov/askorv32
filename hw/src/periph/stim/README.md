Таймер STIM
===========

Простой таймер со счётом вверх, вниз и вверх-вниз, предделителем, выходом сравнения (ШИМ) и прерыванием по событию обновления. По устройству похож на базовые таймеры STM32.

| Файл | Назначение |
|---|---|
| `stim.sv` | модуль `stim_top` (регистры, по шаблону `periph_regs`) и `simple_tim` (счётчик) |
| `tb_stim.sv` | тест: `py hw/sim/run_periph_tests.py stim` |
| `fw/Core/Inc/tim.h`, `fw/Core/Src/tim.c` | библиотека на Си |

## Подключение

Подключает конфигуратор ПЛИС (блок STIM в `fw/riscv.gwsoc`): окно адресов — по умолчанию `0x1300_0000`, выход сравнения — на выбранный вывод.

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `MEMORY_TYPE` | 0 | 1 — данные чтения на следующем такте (шина с BSRAM, как в ПЛИС), 0 — в том же такте |
| `WIDTH` | 16 | разрядность предделителя, периода, сравнения и счётчика |

| Порт | Смысл |
|---|---|
| `clk`, `rst` | такт и сброс шины периферии (`clk_per`, `rst_per` процессора) |
| `Write`, `Addr`, `WData`, `RData` | шина регистров |
| `tim_out` | выход сравнения: 1, пока `CNT < PUL` |
| `irq` | запрос прерывания: `SR.UIF & CR.UIE`, через регистр (на такт позже флага) |

Прерывание по умолчанию — источник 1 PLIC (`PLIC_SRC_STIM`, обработчик `PLIC_STIM_IRQHandler` — имена из `soc.h`); в конфигураторе его можно перевести на локальную линию LI*n*.

## Регистры

| Смещение | Имя | Доступ | Биты | Смысл |
|---|---|---|---|---|
| `0x00` | `PR` | чтение/запись | `[WIDTH-1:0]` | предделитель: счётчик считает раз в `PR + 1` тактов |
| `0x04` | `CR` | чтение/запись | `[1:0] CM` | режим: 0 — вверх, 1 — вниз, 2 — вверх-вниз |
| | | | `[2] ARP` | предзагрузка периода: новый `PER` вступает в силу на перезагрузке счётчика |
| | | | `[3] EN` | включение |
| | | | `[4] UIE` | разрешение прерывания по событию обновления |
| `0x08` | `PER` | чтение/запись | `[WIDTH-1:0]` | период: счёт вверх — до `PER`, вниз — от `PER` |
| `0x0C` | `PUL` | чтение/запись | `[WIDTH-1:0]` | значение сравнения для `tim_out` |
| `0x10` | `CNT` | чтение | `[WIDTH-1:0]` | текущее значение счётчика |
| `0x14` | `SR` | чтение, запись 1 | `[0] UIF` | событие обновления; сбрасывается записью 1 (установка важнее одновременного сброса) |

Разряды старше `WIDTH` (у `CR` — старше 4) при записи отбрасываются, при чтении — 0. Запись с байтовыми стробами меняет только выбранные байты. После сброса все регистры — 0.

## Как работает

**Событие обновления** ставит `SR.UIF`:
- счёт вверх: счётчик дошёл до `PER` (перезагрузка в 0). Сравнение `CNT >= PER`, поэтому период можно уменьшить на ходу;
- счёт вниз: счётчик дошёл до 0 (перезагрузка значением `PER`);
- вверх-вниз: смена направления — в вершине (`PER`) и на нуле.

**Периоды** (в тактах шины `SYSCLK_HZ`):
- вверх и вниз: `(PR + 1) · (PER + 1)`;
- вверх-вниз: между событиями `(PR + 1) · PER`.

**Выход сравнения** `tim_out = (CNT < PUL)`: при счёте вверх это ШИМ с периодом `PER + 1` и скважностью `PUL / (PER + 1)`.

**Выключенный таймер** (`EN = 0`): предделитель стоит в нуле, теневой регистр периода повторяет `PER`. Первый период после включения — полный.

## Библиотека на Си (`tim.h`)

| Функция | Действие |
|---|---|
| `STIM_InitPeriodic(Prescaler, Period)` | счёт вверх, событие каждые `(Prescaler + 1) · (Period + 1)` тактов; таймер не запускается, флаг сброшен |
| `STIM_Init()` | настройка по умолчанию из `tim.h`: тик 1 мс (`STIM_PRESCALER`), `STIM_PERIOD`, `STIM_COUNTER_MODE` |
| `STIM_STATE(TIM_ENABLE / TIM_DISABLE)` | запуск и остановка (`CR.EN`) |
| `STIM_SET_PRESCALER`, `STIM_SET_PERIOD`, `STIM_SET_PULSE`, `STIM_SET_COUNTER_MODE` | запись `PR`, `PER`, `PUL`, `CR.CM` |
| `STIM_GET_COUNT()` | чтение `CNT` |
| `STIM_IT_STATE(TIM_ENABLE / TIM_DISABLE)` | разрешение прерывания (`CR.UIE`) |
| `STIM_GET_FLAG_UPDATE()`, `STIM_CLEAR_FLAG_UPDATE()` | чтение и сброс `SR.UIF` |

`STIM_WIDTH` в `soc.h` (создаёт конфигуратор) совпадает с параметром `WIDTH`. `STIM_PRESCALER` считается от `SYSCLK_HZ`.

## Примеры

Прерывание каждые 500 мс на линии LI0 (обработчик — `STIM_IRQHandler`, имя задано в таблице векторов `start.S`):

```c
#include "tim.h"
#include "gpio.h"
#include "core_riscv.h"

__IRQ void STIM_IRQHandler(void)
{
    STIM_CLEAR_FLAG_UPDATE();          //иначе после выхода прерывание придёт снова
    GPIO_WritePin(GPIO_LED0, !GPIO_ReadPin(GPIO_LED0));
}

void timer_start(void)
{
    STIM_InitPeriodic(SYSCLK_HZ / 1000U - 1U, 500U - 1U);   //тик 1 мс, период 500 тиков
    STIM_IT_STATE(TIM_ENABLE);
    IRQ_Enable(STIM_IRQn);             //LI0 в mie
    __enable_irq();
    STIM_STATE(TIM_ENABLE);
}
```

ШИМ 25 % с частотой `SYSCLK_HZ / 1000` на выходе `tim_out`:

```c
STIM_InitPeriodic(0, 999);   //период 1000 тактов
STIM_SET_PULSE(250);         //1, пока CNT < 250
STIM_STATE(TIM_ENABLE);
```

Полные примеры — `fw/Core/Src/main.c` (EXAMPLE 1 и 3), подробности о прерываниях — `hw/info/interrupts.md`.

## Тест (`tb_stim.sv`)

Через шину регистров, 28 проверок:
- значения после сброса, разрядность регистров, байтовая запись;
- период события обновления в режимах вверх, вниз, вверх-вниз и с предделителем;
- счёт `CNT`, флаг `UIF` (установка, сброс записью 1, запись 0 не сбрасывает);
- запрос `irq` с `UIE` и без, снятие запроса сбросом флага;
- скважность `tim_out` при двух значениях `PUL`, остановка выключенного таймера.
