GPIO
====

Дискретные входы/выходы: до 32 линий, у каждой своё направление.

| Файл | Назначение |
|---|---|
| `gpio.sv` | модуль `gpio_top` (регистры по шаблону `periph_regs`) |
| `tb_gpio.sv` | тест: `py hw/sim/run_periph_tests.py gpio` |
| `fw/Core/Inc/gpio.h`, `fw/Core/Src/gpio.c` | библиотека на Си |

## Подключение

Подключает конфигуратор ПЛИС (блок GPIO в `fw/riscv.gwsoc`): окно адресов — по умолчанию `0x1100_0000`. Линии — выбранные выводы ПЛИС в порядке списка, линия 0 — младший разряд.

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `MEMORY_TYPE` | 0 | 1 — данные чтения на следующем такте (шина с BSRAM, как в ПЛИС), 0 — в том же такте |
| `WIDTH` | 32 | число линий (1…32); задаёт конфигуратор по числу выбранных выводов |

| Порт | Смысл |
|---|---|
| `clk`, `rst` | такт и сброс шины периферии (`clk_per`, `rst_per` процессора) |
| `Write`, `Addr`, `WData`, `RData` | шина регистров |
| `io_ports[WIDTH-1:0]` | двунаправленные выводы |

## Регистры

| Смещение | Имя | Доступ | Смысл |
|---|---|---|---|
| `0x00` | `MODE` | чтение/запись | направление линии: 1 — выход, 0 — вход |
| `0x04` | `OUT` | чтение/запись | уровень выхода |
| `0x08` | `IN` | чтение | состояние выводов: для входа — внешний уровень, для выхода — выводимый |

Разряды старше `WIDTH` не пишутся и читаются как 0. Запись с байтовыми стробами меняет только выбранные байты.

**Сброс** (кнопка или отладчик): `MODE = 0` и `OUT = 0`, то есть все линии — входы. Выводы отпускаются, внешние цепи не получают случайных уровней. До 2026-09-30 регистры не сбрасывались.

Выход меняется в такте записи. `IN` — прямое чтение выводов без синхронизатора: для медленных сигналов (кнопки) этого достаточно. Для быстрых асинхронных сигналов нужен свой синхронизатор в устройстве.

## Библиотека на Си (`gpio.h`)

| Функция | Действие |
|---|---|
| `GPIO_Init()` | начальная настройка направлений (см. `gpio.c`) |
| `GPIO_PinMode(pin, GPIO_MODE_OUTPUT / GPIO_MODE_INPUT)` | направление одной линии |
| `GPIO_WritePin(pin, GPIO_PIN_SET / GPIO_PIN_RESET)` | уровень одной линии |
| `GPIO_ReadPin(pin)` | состояние одной линии |
| `GPIO_PinsMode(mask)`, `GPIO_WritePins(value)`, `GPIO_ReadPins()` | все линии сразу |

Имена линий платы (`GPIO_LED0…LED5`, `GPIO_GMB_DI1…`) заданы в `gpio.h` и должны совпадать с порядком выводов в конфигурации ПЛИС.

## Пример

```c
#include "gpio.h"

GPIO_PinMode(GPIO_LED0, GPIO_MODE_OUTPUT);
GPIO_WritePin(GPIO_LED0, GPIO_PIN_SET);
if (GPIO_ReadPin(GPIO_GMB_DI1)) { /* ... */ }
```

Функции работают как чтение-изменение-запись: из прерывания и из основного цикла одну линию трогать нельзя без запрета прерываний.

## Тест (`tb_gpio.sv`)

8 линий, 16 проверок:
- после сброса все линии — входы и выводы отпущены;
- `OUT` выводится только там, где `MODE = 1`;
- `IN` читает и внешние уровни, и свои выходы;
- разряды выше `WIDTH`, байтовые стробы;
- сброс во время работы возвращает линии во входы.
