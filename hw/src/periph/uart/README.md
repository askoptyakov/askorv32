UART — приёмопередатчик
=======================

Асинхронный приёмопередатчик с FIFO на приём и передачу, прерываниями по заполнению FIFO, контролем чётности и флагами ошибок. Регистры устроены как у UART SiFive (FE310-G002, глава 18) и расширены чётностью (`cfg`) и флагами ошибок (`err`).

| Файл | Назначение |
|---|---|
| `uart.sv` | модуль `uart_top`: регистры по шаблону `periph_regs`, FIFO, передатчик, приёмник |
| `tb_uart.sv` | тест: `py hw/sim/run_periph_tests.py uart` |
| `fw/Core/Inc/uart.h`, `fw/Core/Src/uart.c` | библиотека на Си |

## Подключение

Подключает конфигуратор ПЛИС (блок UART в `fw/riscv.gwsoc`): окно адресов — по умолчанию `0x1400_0000`, выводы TX и RX, скорость, чётность, стоп-биты и глубина FIFO после сброса. На Tang Nano 9K к UART программатора BL702 идут выводы **17** (TX ПЛИС → RX BL702) и **18** (RX ПЛИС ← TX BL702), банк 2, LVCMOS33. На ПК это второй COM-порт программатора (интерфейс 1 FT2232).

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `MEMORY_TYPE` | 0 | 1 — данные чтения на следующем такте (шина с BSRAM), 0 — в том же такте |
| `DEPTH` | 16 | глубина FIFO приёма и передачи: 8, 16 или 32 байта |
| `DIV_INIT` | 390 | `div` после сброса: `f_clk / скорость − 1` (390 — 115200 при 45 МГц) |
| `STOP_INIT` | 1 | стоп-битов после сброса: 1 или 2 |
| `PARITY_INIT` | 0 | чётность после сброса: 0 — нет, 1 — even, 2 — odd |

Конфигуратор считает `DIV_INIT` от частоты шины периферии и проверяет ошибку скорости: больше 1 % — предупреждение, больше 2 % — ошибка. Те же значения он пишет в `soc.h`: `UART_BAUD`, `UART_PARITY_DEFAULT`, `UART_STOP_DEFAULT`, `UART_FIFO_DEPTH`.

| Порт | Смысл |
|---|---|
| `clk`, `rst` | такт и сброс шины периферии |
| `Write`, `Read`, `Addr`, `WData`, `RData` | шина регистров; `Read` — строб чтения (выборка байта из FIFO приёма) |
| `tx` | выход передатчика, в покое 1 |
| `rx` | вход приёмника (асинхронный, внутри — синхронизатор на 2 триггера) |
| `irq` | запрос прерывания `|(ie & ip)`, через регистр |

Прерывание по умолчанию — источник PLIC (номер — в `soc.h`, `PLIC_SRC_UART`); в конфигураторе его можно перевести на локальную линию LI*n*.

## Регистры

| Смещение | Имя | Доступ | Биты | Смысл |
|---|---|---|---|---|
| `0x00` | `TXDATA` | запись | `[7:0]` | байт в FIFO передачи; при полном FIFO байт отбрасывается |
| | | чтение | `[31] full` | FIFO передачи полон |
| `0x04` | `RXDATA` | чтение | `[7:0]` | байт из FIFO приёма; чтение выбирает его из FIFO |
| | | | `[31] empty` | FIFO был пуст, данные 0 (ничего не выбрано) |
| `0x08` | `TXCTRL` | чтение/запись | `[0] txen` | передача разрешена |
| | | | `[1] nstop` | 0 — один стоп-бит, 1 — два |
| | | | `[20:16] txcnt` | порог: `ip.txwm`, пока в FIFO передачи **меньше** `txcnt` байт |
| `0x0C` | `RXCTRL` | чтение/запись | `[0] rxen` | приём разрешён |
| | | | `[20:16] rxcnt` | порог: `ip.rxwm`, пока в FIFO приёма **больше** `rxcnt` байт |
| `0x10` | `IE` | чтение/запись | `[0] txwm`, `[1] rxwm`, `[2] err` | разрешение прерываний |
| `0x14` | `IP` | чтение | `[0] txwm`, `[1] rxwm`, `[2] err` | ожидающие прерывания (`err` — есть флаг в `ERR`) |
| `0x18` | `DIV` | чтение/запись | `[15:0]` | делитель: скорость = `f_clk / (DIV + 1)`, `DIV ≥ 7` |
| `0x1C` | `CFG` | чтение/запись | `[0] pe`, `[1] po` | бит чётности есть; 1 — нечётность (odd), 0 — чётность (even) |
| `0x20` | `ERR` | чтение, запись 1 | `[0] frame`, `[1] parity`, `[2] overrun` | ошибки приёма: стоп-бит 0; чётность не сошлась; байт потерян (FIFO приёма был полон) |

Отличия от SiFive: поля `txcnt`/`rxcnt` — 5 бит (`[20:16]`, у SiFive `[18:16]`), чтобы порог доходил до глубины FIFO 16 и 32; добавлены `CFG`, `ERR` и бит `ie/ip[2]`.

После сброса: `txen = rxen = 0`, `IE = 0`, `ERR = 0`, пороги 0; `DIV`, `nstop` и `CFG` — из параметров.

## Как работает

**Кадр:** старт-бит 0, 8 бит данных младшим битом вперёд, бит чётности (если `pe`), 1 или 2 стоп-бита. Один бит — `DIV + 1` тактов.

**Передатчик** берёт байт из FIFO, когда `txen = 1` и сдвиговый регистр свободен, и сдвигает кадр целиком (до 12 бит). Сброс `txen` останавливает выдачу после текущего кадра.

**Приёмник** ловит спад линии и проверяет старт-бит в середине; каждый бит берётся в середине как большинство из трёх соседних отсчётов (помехоустойчивость к коротким выбросам). Принятый байт попадает в FIFO, даже если чётность или стоп-бит ошибочны, — ошибка отмечается во флаге `ERR`. Если FIFO полон, байт теряется и ставится `overrun`.

**Прерывания по заполнению FIFO** (watermark):
- приём: `rxwm` горит, пока в FIFO больше `rxcnt` байт. `rxcnt = 0` — прерывание на каждый байт, `rxcnt = 7` — когда набралось 8 байт (пакет);
- передача: `txwm` горит, пока в FIFO меньше `txcnt` байт. Обработчик дописывает FIFO, а когда передавать нечего — снимает `ie.txwm`.

Флаги `ip` — уровни, а не события: обработчик должен убрать причину (прочитать FIFO, дописать FIFO или сбросить `ie`), иначе прерывание повторится.

## Библиотека на Си (`uart.h`)

Строки в прошивке — в cp1251 (кодировка проекта), терминал на ПК обычно в UTF-8. `UART_PutText` перекодирует cp1251 → UTF-8 (кириллица, Ё/ё, °, « », №), `UART_Utf8ToCp1251` — обратно (`UART_TEXT_UTF8 = 0` отключает перекодировку).

| Функция | Действие |
|---|---|
| `UART_Init(baud, parity, stop)` | скорость, чётность (`UART_PARITY_NONE/EVEN/ODD`), стоп-биты; очищает FIFO приёма и флаги, включает приём и передачу |
| `UART_InitDefault()` | то же с настройками из конфигуратора (`soc.h`) |
| `UART_PutChar`, `UART_PutString`, `UART_PutText` | передача байта, строки как есть, строки cp1251 (ждёт места в FIFO) |
| `UART_PutDec`, `UART_PutHex` | число десятичное со знаком, шестнадцатеричное |
| `UART_GetChar` | байт или −1, не ждёт |
| `UART_ReadChar`, `UART_ReadLine(buf, size, echo)` | ждёт байт; строка до CR/LF с эхом и Backspace |
| `UART_GetErrors`, `UART_ClearErrors` | флаги `ERR` |

**Режим прерываний** — кольцевые буферы в ОЗУ (`UART_RING_SIZE`, по умолчанию 64):

| Функция | Действие |
|---|---|
| `UART_IT_Start(rx_threshold)` | порог `rxcnt`, `txcnt = FIFO/2`, разрешение `rxwm`, источник PLIC (или локальная линия) |
| `UART_IT_Write(data, len)` | в буфер передачи, возвращает, сколько поместилось (не ждёт) |
| `UART_IT_PutText(s)` | строка cp1251, ждёт места в буфере |
| `UART_IT_Read(data, len)`, `UART_IT_Available()` | из буфера приёма |
| `UART_IRQ_Service()` | тело обработчика: FIFO приёма → буфер, буфер передачи → FIFO |

## Примеры

Опрос (пример 3 в `fw/Core/Src/main.c`):

```c
#include "uart.h"

char line[64];
UART_InitDefault();
UART_PutText("Введите число: ");
UART_ReadLine(line, sizeof line, 1);
UART_PutDec(2 * parse_int(line));
```

Прерывания (пример 4): обработчик по имени из `soc.h`.

```c
__IRQ void PLIC_UART_IRQHandler(void) {
    UART_IRQ_Service();                 //FIFO <-> кольцевые буферы
    PLIC_Complete(PLIC_SRC_UART);
}

UART_InitDefault();
PLIC_Init();
UART_IT_Start(0);                       //Прерывание приёма на каждый байт
__enable_irq();
UART_IT_PutText("Привет\r\n");
char c;
while (UART_IT_Read(&c, 1)) { ... }
```

Пакет из 8 байт без прерывания на каждый байт (пример 5): `RXCTRL = EN | (7 << 16)`, `IE = RXWM`; обработчик читает 8 раз `RXDATA`.

## Тест (`tb_uart.sv`)

67 проверок. Основной экземпляр — FIFO на 8 байт; второй (адрес с битом 12) — FIFO 16, 2 стоп-бита, odd, `DIV_INIT = 1234`: на нём проверяются значения после сброса из параметров.
- сброс и разрядность регистров, байтовая запись полей `txcnt`/`rxcnt`;
- кадры передатчика: 8-N-1, два стоп-бита вплотную, бит чётности even и odd;
- приём кадров от модели передатчика тестбенча: `rxdata`, `empty`, флаги `frame` и `parity` и их сброс записью 1;
- FIFO передачи: накопление при `txen = 0`, `full`, отброшенный лишний байт, порядок;
- порог `txcnt` и прерывание `txwm`; петля `tx → rx`, порог `rxcnt` и прерывание `rxwm`;
- переполнение FIFO приёма: потерянный байт, `overrun` и прерывание `err`.
